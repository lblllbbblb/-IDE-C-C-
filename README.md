IDE功能介绍：
基本功能：
  文件处理：支持打开、保存、另存为、新建文件
  文字编辑：包含全选、复制、粘贴、剪切、查找与替换、撤销、恢复功能
  构建功能：可进行编译、运行、编译并运行操作
  编译反馈：编译失败时提示错误位置与类型；编译成功时提示完成
  拓展功能：
显示与交互：支持深浅模式切换（含定制语法高亮），左侧显示行数，支持函数折叠，左下角显示光标行列位置
  调试功能：内置调试能力，调试窗口可移动、独立外置
  AI 助手：集成 DeepSeek 模型，可通过对话区沟通，自动加载代码上下文，支持一键插入 AI 生成的代码建议
  智能补全：基于标准库知识，输入时推荐变量、函数、关键字，优化 C++ 上下文理解
  编译支持：基于 G++ 编译器，支持 C 与 C++ 语言编译
